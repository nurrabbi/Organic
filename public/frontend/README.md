# Organic E-commerce Frontend Template

Multi-page static frontend created from the supplied Organic HTML template.

## Pages
- index.html
- about.html
- shop.html
- single-product.html
- cart.html
- checkout.html
- transaction-gateway.html
- order-tracking.html
- blog.html
- single-post.html
- styles.html
- contact.html
- thank-you.html
- my-account.html
- messaging.html
- product-review.html
- feedback.html
- 404.html

## Notes
- Original Bootstrap, Swiper, vendor CSS/JS, fonts and image assets are preserved.
- This is a frontend/static prototype. Forms, payments, authentication and tracking are visual only.
- Small prototype interactions are in js/frontend-pages.js.
- Open index.html in a browser to start.


## Account pages
- `login.html` — centered login page with Google, Email, and Facebook provider buttons
- `register.html` — centered registration page
- `my-account.html` — profile, orders/coins, feedback and reviews dashboard
